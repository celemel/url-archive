# マイリンク

選んだファイルからリンクを読み取り、タップひとつで開ける一覧にする、ブラウザだけで動く単一HTMLツールです。
サーバー不要・外部送信なし。読み込んだ内容は各端末のブラウザ内にのみ保存されます。

## 使い方

1. `url-archive.html` を開く（下記の公開方法参照）
2. 「まとめて選ぶ」または「個別に選ぶ」でファイルを選択
3. 一覧に追加されます。タップでそのままリンクを開けます

同じ手順で選び直すだけで追加されます。既に登録済みのものは自動でスキップされるため、まとめて選び直しても重複しません。

## 公開方法（GitHub Pages）

1. このリポジトリの Settings → Pages
2. Source を「Deploy from a branch」、Branch を `main` / `root` に設定
3. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/url-archive.html` でアクセス可能に
4. iPhoneのSafariでそのURLを開き、共有ボタン→「ホーム画面に追加」で
   アプリのようにワンタップ起動できます

## データについて

- 読み込んだ内容は、ブラウザ内にのみ保存されます（サーバーには送信されません）
- 端末・ブラウザが変わるとデータは共有されません
- 検索・個別削除・全削除に対応しています
- リポジトリ自体には、読み込んだ内容は一切含まれません（ツール本体のコードのみ）

## ファイル構成

```
url-archive.html   … ツール本体（このファイル1つで完結）
README.md          … このファイル
```
